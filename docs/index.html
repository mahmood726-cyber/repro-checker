reprocheck

Meta-analysis reproducibility checker — re-derive a paper's pooled statistics from the primary sources and flag what doesn't hold up.
Truth-first. A number is reported as reproduced only when it actually recomputes from the supplied / re-sourced data. Missing data yields an honest cannot-verify. Nothing is fabricated.
off = fully offline (recompute + structural flags only)
Engine verified for parity with the Python reference under Node. Live in-browser re-sourcing depends on the registries permitting cross-origin requests; if blocked, use the CLI (python -m reprocheck.cli check … ) for full citation re-sourcing. Standard-library / dependency-free. MIT.
